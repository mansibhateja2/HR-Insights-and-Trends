# 📊 HR Insights & Trends Dashboard

## 📌 Project Overview
The HR Insights & Trends project focuses on analyzing employee data to understand workforce distribution, employee attrition, salary trends, and employee demographics using Power BI.

## 🎯 Project Objectives
- Analyze employee attrition.
- Identify employee distribution across departments.
- Understand salary and age patterns.
- Analyze employee performance and satisfaction.
- Identify trends to support HR decision-making.

## 🛠️ Tools & Technologies
- Power BI
- Microsoft Excel
- DAX
- Data Cleaning
- Data Visualization

## 📈 Key Performance Indicators (KPIs)
- Total Employees
- Attrition Count
- Attrition Rate
- Average Employee Age
- Average Salary
- Employee Distribution by Department

## 📊 Dashboard Insights
The dashboard helps HR teams understand:
- Department-wise employee distribution.
- Employee attrition trends.
- Age-wise workforce analysis.
- Salary distribution.
- Employee experience and satisfaction.

## 💡 Key Learnings
- Data cleaning and transformation.
- Creating DAX measures.
- Building interactive dashboards.
- Analyzing HR trends.
- Presenting business insights through visualization.
